# Boomy's Zeus Scripts
All my Arma 3 Public Zeus scripts, compositions, and some Aegis stuff in one place. Including the horrible ones!

I've gotten many requests over the past two years for some of the scripts and compositions I've made or had for game mastering in Arma 3's official Zeus servers. Given the imminent release of Arma 4 sometime over the next year or two, I decided to release them in a tidy GitHub repo for y'all. They can all probably be coded way better, but it doesn't really matter.
